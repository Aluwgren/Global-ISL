Maintenance prerelease for **Skyrim SE 1.5.97 / SKSE 2.0.20 / compatible Open Shaders**.

Download **GlobalPointLightISL-1.5-test22.1.zip** and install it as a normal mod in **MO2 or Vortex**. The ZIP root contains `SKSE/Plugins`; no FOMOD or folder adjustment is required. Replace the previous Global ISL installation and back up customized INI settings. For manual installation, extract into Skyrim's `Data` directory.

Changes:

- Fixes failed hook rollbacks that could leave calls into freed memory or lose Effects11 forwarding.
- Prevents stale continuous-spell state from following reused light pointers or surviving scene generations; handles nested creations and contention conservatively.
- Preserves detached fire-light associations during load settling and clears old particle-color anchors after transitions.
- Requires complete definition scanning before creating detached fire associations.
- Adds regression tests and verified mod-manager packaging.

**Fire-associated hazards retain the standard fire color.** The test22 INI and lighting defaults are unchanged: fire RGB 255/140/60, bias ceiling 1.0, ordinary radius cap disabled, and hand/impact radii 40/20. No FaceGen Shadow Softener or sun/moon lighting changes are included.

Validation includes 22 native regression checks against the actual source with simulated Win32 services, optimized LLVM 19 compilation with warnings as errors, static analysis, PE/import/export checks, repeated DLL/ZIP builds, and installation-layout/checksum verification.

**This DLL has not yet been tested in Skyrim.** Keep the tested test22 build available for rollback. This is a prerelease, not a claim of new in-game validation or support for every Open Shaders version. Long-session cache saturation remains a follow-up review item.
